# 🛒 React Redux Shopping Cart

A simple e-commerce web application built using React.js and Redux Toolkit. This project allows users to browse products, add items to cart, manage quantity, and calculate total price.

---

## ✨ Features

- View list of products  
- Add products to cart  
- Remove products from cart  
- Increase / decrease quantity  
- Cart item counter in navbar  
- Total price calculation  
- Data stored using LocalStorage  
- Responsive design for all devices  

---

## 🛠 Tech Stack

- React.js  
- Redux Toolkit  
- React Router  
- JavaScript  
- CSS
